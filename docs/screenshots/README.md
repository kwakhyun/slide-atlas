# 현재 UI 스크린샷

2026-09-05 로컬 프로덕션 빌드에서 촬영했습니다. PGlite 메모리 저장과 규칙 기반 생성 모드를 사용했으며, 공개 배포나 실제 AI 호출의 증빙은 아닙니다.

각 화면은 별도의 새 데모 작업 공간입니다. 첫 방문 안내를 닫고 글꼴과 데이터를 불러온 뒤, 페이지 맨 위에서 보이는 영역만 촬영합니다. 데스크톱은 1440 × 1000px, 모바일은 390 × 844px이며 배율은 1입니다. 전체 페이지 캡처에서 고정 탐색 메뉴가 중간에 나타나는 혼동을 피하고 실제 화면의 배치를 보여줍니다.

## 다시 촬영하기

별도 터미널에서 AI를 끈 로컬 프로덕션 서버를 실행한 뒤 아래 명령을 사용합니다. 문서 캡처에는 새 데모 작업 공간이 만들어지므로 로컬 검증용 서버를 사용합니다.

```sh
DEMO_BASE_URL=http://127.0.0.1:3107 node --import tsx scripts/capture-screenshots.ts
DEMO_BASE_URL=http://127.0.0.1:3107 npm run demo:capture
```

[스크린샷 스크립트](../../scripts/capture-screenshots.ts)는 위 PNG 7장을 갱신합니다. [데모 녹화 스크립트](../../scripts/capture-demo.ts)는 생성, 편집과 저장, 검색, 검수, 실험의 실제 동작을 촬영합니다. README의 [제품 흐름 영상](../demo/slide-atlas-walkthrough.webm)도 같은 빌드에서 다시 녹화했습니다.
