## 측정과 검증 방법

`npm run eval:editor`는 12장 덱의 첫 슬라이드를 100번 수정합니다. 초기 계산을 포함해 이전 방식은 1,313회, 변경된 방식은 112회 검사했습니다. 같은 로컬 실행에서 계산 시간은 117.21ms와 11.87ms였습니다. [측정 데이터](editor-benchmark.json)를 보관합니다. 실제 브라우저 입력 지연이나 사용자 기기의 속도를 나타내는 수치는 아니며 실행 시간은 환경에 따라 달라집니다.

회귀 검사는 작업 공간 조회에 오류를 반환하도록 설정한 상태에서 두 번 저장해 버전 충돌이 나지 않는지, 연속 입력을 되돌리면 저장된 내용과 상태로 돌아오는지, 실패한 보조 데이터 조회를 재시도할 수 있는지, 모바일 메뉴 이름이 보이고 안내 글자가 최소 12px인지 확인합니다. 원문과 템플릿 변경에 따른 검사 캐시 무효화와 세션별 데이터 격리도 검사합니다.

전체 검사 결과와 현재 소스 기준은 [로컬 검증 기록](local-verification.json)에서 확인합니다. 기존 템플릿 버전 보존과 숫자 처리 개선은 [앞선 개선 기록](improvements-2026-09-05.md)에 있습니다.
