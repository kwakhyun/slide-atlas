# 기능 고도화 기록

2026-09-05의 추가 기능 구현입니다. 로컬 프로덕션 빌드에서 검증하며, 공개 배포나 외부 사용자 관찰의 결과와 구분합니다.

## 구현한 기능

| 순서 | 기능                    | 사용 방법과 구현 범위                                                                                                                                                                                  |
| ---- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1    | 초안 보관과 복구        | 편집 중 IndexedDB에 작업 공간, 프레젠테이션과 작성 탭별 초안을 보관합니다. 다시 열면 서버 저장본과 비교하고 복구하거나 삭제할 수 있습니다. 서버 버전이 달라졌다면 저장 시 기존 충돌 검사를 적용합니다. |
| 2    | 품질 경고 해결          | 빈 필수 내용, 예상 넘침과 원문 수치 오류에 해당하는 입력란으로 이동하고 슬롯을 강조합니다. 현재 슬라이드의 SVG 텍스트 경계도 측정해 실제 영역 초과를 표시합니다.                                       |
| 3    | 부분 재생성과 원문 근거 | Studio 하단에서 선택한 슬롯 또는 슬라이드의 후보를 생성하고 적용 전에 비교합니다. 원문 후보는 어휘와 수치 일치로 제안하며 사용자가 문장 범위를 직접 연결할 수 있습니다.                                |
| 4    | 템플릿 변경 영향        | 승인 템플릿 상세에서 영향을 받는 프레젠테이션과 적용 전후 값, 품질 경고를 확인합니다. 선택한 프레젠테이션마다 버전을 검사하고 적용 결과를 반환합니다. 옮길 수 없는 내용은 적용하지 않습니다.           |
| 5    | PPTX 후보 일괄 등록     | 추출 결과에서 여러 후보를 선택해 초안으로 등록합니다. 현재 카탈로그와 같은 입력은 건너뛰며 실패한 항목을 다시 시도할 수 있습니다. 자동 승인하지 않습니다.                                              |
| 6    | 실험 설정 사본          | 실험실에서 평가셋과 검색 가중치를 JSON으로 편집하거나 가져옵니다. 설정마다 별도 ID와 SHA-256을 보관하고 실행 결과에 연결합니다. 실패 질의로 회귀 설정을 준비할 수 있습니다.                            |
| 7    | 브랜드 스타일           | 색상과 글꼴을 저장하고 대비 조건을 검사합니다. 수정은 새 버전으로 저장하며 슬라이드에는 적용 당시 사본을 보관합니다. SVG와 PPTX가 같은 색상과 지정 글꼴을 사용합니다.                                  |
| 8    | 계정과 팀               | `/team`에서 자체 계정을 만들거나 로그인하고 초대 코드로 작업 공간에 참여합니다. 소유자, 작성자, 검수자와 열람자의 권한은 서버에서 확인합니다. 검수 댓글과 해결 상태를 기록할 수 있습니다.              |
| 9    | 읽기 전용 공유          | 저장된 프레젠테이션의 사본을 공유합니다. 링크는 1~7일 후 만료되며 발급자가 해제할 수 있습니다. 원문 브리프, 슬롯 근거와 생성 사용량은 공유 사본에서 제외합니다.                                        |

## 데이터 변경과 복구

- `schema_migrations`에 SQL 파일명과 SHA-256을 기록합니다. 적용된 파일이 바뀌면 초기화를 중단하므로, 다음 변경은 새 SQL 파일로 추가해야 합니다. PostgreSQL은 advisory lock 안에서, PGlite는 트랜잭션 안에서 마이그레이션을 실행합니다.
- 새 부분 재생성 API는 요청 ID와 입력 해시를 예약합니다. 같은 ID와 입력의 완료 요청은 보관된 후보를 반환하며 모델을 다시 호출하지 않습니다. 처리 중이거나 실패한 요청을 같은 ID로 재실행하지 않습니다. 새 요청은 사용자가 다시 시작합니다.
- 부분 재생성 후보를 적용해도 서버 저장 전에는 되돌릴 수 있습니다. 다른 편집이 발생하거나 서버 버전이 바뀌면 해당 후보를 바로 적용할 수 없습니다.
- 근거 연결에는 원문의 시작과 끝 위치, 연결 당시 슬롯 내용을 보관합니다. 내용이 바뀌면 재확인을 표시합니다. 템플릿 일괄 갱신 시에는 근거 연결을 해제하고 다시 확인하도록 합니다.
- 브랜드는 슬라이드 내부에 버전 사본을 저장합니다. 브랜드의 새 버전을 저장해도 기존 프레젠테이션이 바뀌지 않습니다.
- 템플릿 일괄 적용은 프레젠테이션별 트랜잭션입니다. 전체 요청을 하나의 트랜잭션으로 처리하지 않으며, 일부 성공과 일부 실패를 각각 표시합니다.

## 계정과 권한

| 역할   | 내용·템플릿 편집, 실험, 공유 | 템플릿 검수 상태 변경 | 검수 댓글 | 팀 초대·권한 해제 |
| ------ | ---------------------------- | --------------------- | --------- | ----------------- |
| 소유자 | 가능                         | 가능                  | 가능      | 가능              |
| 작성자 | 가능                         | 불가                  | 가능      | 불가              |
| 검수자 | 불가                         | 가능                  | 가능      | 불가              |
| 열람자 | 불가                         | 불가                  | 불가      | 불가              |

비밀번호는 무작위 salt와 scrypt로 처리합니다. 로그인 세션과 초대 코드는 서버에 해시만 저장합니다. 계정을 연결한 뒤에는 이전 익명 쿠키로 해당 작업 공간에 접근할 수 없습니다. 초대 코드는 24시간 이내 한 번만 사용할 수 있고, 권한을 해제하면 해당 작업 공간의 로그인 세션도 삭제합니다. 비밀번호 변경 시 다른 로그인 세션을 종료합니다.

익명 작업 공간의 보관 정책은 기존과 같은 7일입니다. 계정에 연결한 작업 공간은 익명 만료 정리에서 제외합니다. 계정 세션은 7일 후 만료되며 다시 로그인할 수 있습니다. 이메일 인증, 비밀번호 분실 복구, SSO, 소유권 이전과 계정 삭제 화면은 제공하지 않습니다. 계정 기능은 데모에서 팀 권한을 검증하기 위한 범위입니다.

## 검증 범위와 한계

최종 단위 및 통합 테스트 95개와 E2E 시나리오 43개가 통과했습니다. 상세 결과는 [로컬 검증 기록](feature-verification-2026-09-05.json)에 있습니다. 계정, 초대, 권한과 공유 검증에는 로컬에서 생성한 테스트 계정을 사용합니다. 실제 모델 호출, 외부 로그인 제공업체 연동이나 외부인 초대는 실행하지 않습니다.

- 브라우저 초안은 서버 저장을 대신하지 않습니다. 저장소가 차단되거나 정리되면 복구할 수 없으며, 7일이 지난 기록은 복구 대상에서 제외하고 다음 쓰기에서 정리합니다. 같은 탭에서 브라우저가 저장을 마치기 전 강제 종료된 마지막 입력은 보관되지 않을 수 있습니다.
- 실제 넘침 검사는 현재 브라우저의 글꼴과 SVG 렌더링을 대상으로 합니다. PowerPoint의 줄바꿈이나 글꼴 대체까지 검증한 결과는 아닙니다.
- 원문 근거 제안과 사용자의 연결 기록은 사실 검증을 자동으로 통과시킨다는 의미가 아닙니다. 단위 환산, 수치와 주장의 연결, 숫자 없는 사실 오류는 사람이 검토해야 합니다.
- 실험 설정은 작업 공간당 50개, 브랜드 버전은 50개, 프레젠테이션별 댓글은 100개, 활성 공유는 20개로 제한합니다. 실험 설정 사본은 수정하지 않고 새로 저장합니다.
- PPTX 일괄 등록의 중복 확인은 현재 브라우저가 조회한 카탈로그와 같은 실행의 성공 항목을 기준으로 합니다. 다른 탭의 동시 등록까지 막는 전역 중복 제약은 아닙니다.
- 공유 링크를 가진 사람은 사본을 볼 수 있습니다. 공유 해제는 이후 서버 접근을 막으며 이미 열람하거나 복사한 내용까지 회수하지는 않습니다.
- 외부 PostgreSQL 환경, 계정의 장기 운영, 다양한 외부 PPTX와 실제 운영자 사용성은 별도 검증이 필요합니다.
