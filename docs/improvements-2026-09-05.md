# 2026-09-05 개선 기록

코드 검토에서 확인한 원문 수치 변형, 사용자 정의 슬롯 매핑 오류, 과거 템플릿 버전 미참조와 저장 대기 중 편집 유실을 수정했습니다. 이 문서는 로컬 수정본의 동작을 설명합니다. 공개 서비스의 기존 배포 기록과는 구분합니다.

## 결과 정확성과 작업 보존

| 기존 문제                                                 | 수정한 동작                                                                                                               | 회귀 검증                                                                                    |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `1,200명`을 `200명`, `-12%`를 `12%`로 추출                | 수치를 먼저 인식하고 숫자 내부 쉼표를 문장 구분에서 제외합니다. 부호, 소수, 복합 단위와 원문의 시작·끝 위치를 보존합니다. | 쉼표, 음수, 단위 변형, 같은 줄의 여러 수치                                                   |
| 사용자 정의 제목 키가 `heading`이면 생성 결과가 비어 있음 | 템플릿의 실제 키, 역할과 배치 순서에 맞춰 값을 할당합니다. 정의하지 않은 키를 추가하지 않습니다.                          | 6개 레이아웃의 키 변경, PPTX 추출 → 등록 → 승인 → 생성 → 편집 → 출력                         |
| 템플릿 수정 후 기존 덱의 배치나 저장 가능 여부가 바뀜     | 화면, 썸네일, 발표, SVG/PPTX/JSON과 저장 검증이 생성 당시 버전 사본을 사용합니다.                                         | 슬롯 변경 후 SVG와 PPTX 내용 유지, 저장·복제, 존재하지 않는 버전 및 다른 작업 공간 사본 거절 |
| 저장 응답 대기 중 입력한 내용이 초안 초기화로 사라짐      | 저장 응답을 편집 상태에 반영할 때까지 편집 도구를 비활성화합니다. 이후 입력은 새 초안에 반영합니다.                       | 응답을 보류한 상태의 입력·스타일·되돌리기·템플릿 변경 잠금과 후속 저장                       |

`template_versions`는 이미 저장하던 사본을 활용합니다. 별도 스키마 변경이나 기존 덱의 일괄 덮어쓰기는 필요하지 않습니다. 참조한 버전을 찾을 수 없으면 `TEMPLATE_VERSION_MISSING`으로 실패하며 최신 버전으로 대체하지 않습니다. 현재 카탈로그는 검색과 새 생성에, 버전 사본은 기존 결과물에 사용합니다.

새 승인 버전은 Studio의 `승인된 vN 적용`으로 적용합니다. 같은 키와 역할을 먼저 보존하고 이름이 달라진 슬롯은 역할과 배치 순서로 연결합니다. 옮기지 못한 내용이 있으면 변경하지 않고 해당 항목을 안내합니다. 적용 후 빈 영역과 넘침을 검토하고 저장하며, 저장 전에는 되돌릴 수 있습니다.

수치 검사는 부호와 명시적인 단위의 변형을 감지합니다. 단위가 없는 값 전용 슬롯은 원문의 같은 수치를 허용합니다. `3억원 → 30000만원` 같은 단위 환산, 수치와 주장의 연결, 숫자 없는 사실 오류는 자동으로 판정하지 않습니다. 원문이 부족한 슬롯은 비워 두고 검토 대상으로 표시합니다.

## 생성과 편집 흐름

첫 안내를 줄이고 생성 완료 후 자동으로 접습니다. 모바일 첫 안내에는 예시 시작 동작만 표시하며 라이브러리와 실험실은 하단 메뉴로 이동할 수 있습니다. 필요하면 `3분 체험 안내 열기`로 다시 볼 수 있습니다. 생성 후에는 내용 편집 탭으로 이동하고 첫 오류 또는 경고가 있는 슬라이드를 선택합니다. 내용 편집 화면에서 전체 덱의 검토 현황과 슬라이드별 바로가기를 제공하며 모바일에서도 해당 내용 입력으로 이동합니다.

슬라이드 목록은 자체 가로 스크롤만 움직이도록 바꿨습니다. 첫 진입이나 슬라이드 선택 때문에 페이지 전체가 아래로 밀리지 않습니다.

## 외부 검증 준비

[사용성 프로토콜](user-study-protocol.md)에 수정 횟수와 막힌 단계의 기록 방법을 추가하고 CSV 집계 도구를 제공합니다. 미완성 입력을 0이나 성공으로 처리하지 않습니다. 합성 데이터로 집계 도구만 검증했으며 실제 참여자 결과는 생성하지 않았습니다.

독립 검색 평가자와 외부 운영자 3~5명의 실제 관찰은 남아 있습니다. [평가 체크리스트](../evaluation/README.md)에 독립성, 입력 고정, 데이터 해시와 결과 공개 기준을 기록했습니다. 이 작업에서는 외부인에게 연락하거나 유료 모델 평가를 실행하지 않았습니다.

## 검증 환경

현재 검사 결과는 [로컬 검증 기록](local-verification.json)을 기준으로 확인합니다. 개발 서버 검사 중 Turbopack 내부 오류가 발생해 프로덕션 빌드 기반 검사와 구분해 기록합니다. Microsoft PowerPoint의 실제 화면 비교와 외부 데이터 정확도 평가는 이번 회귀 테스트의 범위에 포함하지 않습니다.
