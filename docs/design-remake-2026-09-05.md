# UI/UX 리메이크

2026-09-05 로컬 작업 공간에 적용한 디자인 변경입니다. Slide Atlas 이름과 실제 데이터 흐름을 유지하면서 밝은 디자인 도구의 탐색 방식과 편집 화면으로 재구성했습니다.

## 공통 디자인

- 청록색을 주요 작업과 선택 상태에 사용하고, 흰색 패널과 연한 회색 배경으로 영역을 구분합니다. 작은 글자는 대비를 확보하기 위해 강조색보다 진한 색을 사용합니다.
- Pretendard, Lucide 아이콘, 8~14px 모서리와 얇은 테두리를 일관되게 적용합니다. 오류와 경고는 별도의 의미 색상을 유지합니다.
- 앱 로고와 탭 아이콘을 맞췄습니다. 참고 서비스의 이름, 로고와 이미지 자산은 제품 화면에 포함하지 않습니다.

## 화면별 변화

| 화면                    | 변경                                                                                                                                                         |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 편집기                  | 데스크톱에서 88px 탐색 메뉴, 내용 입력 패널과 넓은 캔버스를 연결합니다. 저장, 발표와 내보내기는 상단에 두고, 브랜드, 댓글과 부분 재생성은 하단에 모았습니다. |
| 템플릿                  | 검색창을 크게 배치하고, 전달 의도를 아이콘 카테고리로 보여줍니다. 템플릿 수는 간단히 표시하고 미리보기 카드가 중심이 되도록 구성했습니다.                    |
| 검수                    | 대기 목록, 미리보기, 검사 결과와 승인 입력을 분리하며 선택한 항목을 청록색으로 표시합니다.                                                                   |
| 실험실                  | 밝은 비교 안내, 결과 카드와 설정 패널로 통일했습니다. 실제 실행 전에는 성과 수치를 표시하지 않습니다.                                                        |
| 계정, 소개, 공유와 발표 | 같은 글꼴, 색상, 버튼과 패널 규칙을 적용했습니다. 발표는 어두운 배경을 유지해 슬라이드에 집중하도록 했습니다.                                                |
| 모바일                  | 하단 탐색 메뉴와 내용 입력/미리보기 전환을 유지하고, 카테고리는 가로로 탐색합니다. 768px와 1024px에서도 내용 수정과 되돌리기를 확인합니다.                   |

슬라이드의 색상과 출력물은 편집기 UI 색상에 영향을 받지 않습니다. 카드는 실제 템플릿의 SVG 미리보기이며, 화면을 꾸미기 위한 가짜 디자인 데이터는 추가하지 않았습니다.

## 확인 방법

[검증 기록](local-verification.json)과 [디자인 QA](../design-qa.md)에 검사 범위와 수정 내역을 기록했습니다. 기본 화면뿐 아니라 편집, 저장, 템플릿 검색, 검수, 브랜드 적용, 계정과 공유의 기존 흐름을 E2E로 확인합니다.

디자인 규칙은 [design-system.css](../src/app/styles/design-system.css)에 있습니다. 모바일에서 앱 영역을 숨겨 넘침을 가리는 대신, 탐색 메뉴 폭과 패널 배치를 전환합니다. 슬라이드 목록과 카테고리처럼 가로 탐색이 필요한 영역만 독립적으로 스크롤됩니다.
