# PPTX 구조 추출 평가

`npm run eval:pptx`는 승인된 12개 템플릿을 편집 가능한 PPTX로 만든 뒤 다시 추출합니다. 레이아웃, 전달 의도, 슬롯 텍스트와 정규화 좌표의 보존 정도를 측정하며 결과를 `docs/pptx-evaluation.json`에 기록합니다.

이 평가는 내보내기와 가져오기 사이의 회귀를 찾는 합성 왕복 검사입니다. 같은 프로젝트가 생성한 단순한 OOXML을 사용하므로 외부 PowerPoint의 다양한 표, 차트, 이미지, 마스터, 그룹 도형과 글꼴을 대표하지 않습니다. 실제 추출 정확도는 외부 제작 파일과 사람이 표시한 정답으로 별도 검증해야 합니다.
