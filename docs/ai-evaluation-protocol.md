# AI 생성 품질 평가 프로토콜

## 목적

실제 모델 연결 여부와 생성 품질을 구분합니다. 자동 검사는 구조 보존, 필수 슬롯, 글자 수, 원문 수치 토큰과 예상 넘침을 측정합니다. 의미가 유지됐는지, 숫자가 올바른 주장에 연결됐는지와 수정 없이 사용할 수 있는지는 사람이 별도로 평가합니다.

## 데이터

`evaluation/ai-cases.json`에는 한국어와 영어, 여섯 가지 전달 의도, 수치가 있는 브리프와 없는 브리프를 포함한 합성 입력 24개가 있습니다. 구현자가 만든 개발셋이므로 실제 사용자 분포나 독립 평가로 표시하지 않습니다.

## 실행 안전장치

모델 호출은 비용이 발생하므로 데이터 파일을 먼저 검토하고 다음과 같이 명시적으로 승인해야 합니다.

```bash
npm run eval:ai -- --live --confirm-cost --output docs/ai-evaluation.json
```

소규모 연결 점검은 `--limit 2`처럼 제한할 수 있습니다. CI에서는 `npm run eval:ai -- --check`만 실행하며 모델을 호출하지 않습니다. 결과 파일에는 브리프와 생성 본문을 다시 저장하지 않고 케이스 ID, 자동 지표, 토큰과 지연 시간만 기록합니다.

## 사람 평가

성공한 각 케이스를 두 명이 독립적으로 검토하고 다음 항목을 `통과`, `실패`, `판단 보류`로 기록합니다.

1. 원문의 의미가 유지됐는가
2. 모든 수치와 단위가 올바른 대상 및 주장에 연결됐는가
3. 중요한 제한이나 불확실성을 삭제하지 않았는가
4. 운영자가 큰 재작성 없이 사용할 수 있는가

의견이 다르면 근거를 남기고 합의한 최종 판정을 별도 기록합니다. 자동 검사를 통과했더라도 사람 평가 전에는 품질 성공으로 집계하지 않습니다.

[`evaluation/ai-human-review.template.csv`](../evaluation/ai-human-review.template.csv)를 복사해 평가자별 행을 작성합니다. `reviewer_id`에는 임의 코드를 사용하고 각 라이브 결과의 `case_id`마다 두 행이 있어야 합니다. 원문과 생성 결과는 평가 환경에서만 보여 주고 공개 결과 파일에는 다시 저장하지 않습니다.
